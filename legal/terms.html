ข้อกำหนดการใช้งาน

ฉบับวันที่ 7 ตุลาคม 2569 (2026) · ใช้กับ Dusktale ทั้งแบบใช้ API Key ของผู้ใช้เอง และบริการแปลของ Dusktale (เข้าสู่ระบบด้วยอีเมล)

สรุปสั้นๆ
  • Dusktale เป็นเครื่องมืออ่านและแปลนิยายด้วย AI เราไม่ได้ฝากหรือเผยแพร่นิยายเอง
  • คุณรับผิดชอบเนื้อหาที่นำมาแปล ถ้าใช้ API Key ของตัวเอง ค่าใช้จ่ายกับผู้ให้บริการ AI เป็นของคุณ ถ้าใช้บริการแปลของ Dusktale ใช้ได้ตามโควตาของแพ็กเกจ
  • คำแปลมาจาก AI อาจผิดพลาด และข้อมูลอยู่ในเครื่องของคุณ ควรสำรองข้อมูลเสมอ

1. การยอมรับข้อกำหนด

เมื่อใช้ Dusktale ถือว่าคุณยอมรับข้อกำหนดนี้และนโยบายความเป็นส่วนตัว ถ้าไม่ยอมรับโปรดหยุดใช้งาน

2. บริการคืออะไร

Dusktale เป็นเว็บแอพที่ช่วยดึงข้อความจากลิงก์หรือไฟล์ที่คุณให้มา แล้วส่งไปแปลกับผู้ให้บริการ AI ที่คุณเลือกด้วย API Key ของคุณ พร้อมเครื่องมือช่วยอ่าน เช่น คลังศัพท์ คู่มือเรื่อง เสียงอ่าน และผู้ช่วย AI แอพทำงานในเบราว์เซอร์ของคุณ ไม่มีเซิร์ฟเวอร์ของเราอยู่ระหว่างทาง

3. ลิขสิทธิ์และเนื้อหาที่คุณนำมาใช้

  • Dusktale ไม่ได้เป็นเจ้าของ ไม่ได้ฝาก และไม่ได้เผยแพร่นิยายใดๆ ลิขสิทธิ์ของต้นฉบับเป็นของผู้เขียนและสำนักพิมพ์
  • ใช้แอพเพื่ออ่านส่วนตัว คุณต้องมีสิทธิเข้าถึงเนื้อหาที่นำมาแปล และปฏิบัติตามข้อกำหนดของเว็บไซต์ต้นทาง
  • ห้ามนำคำแปลของงานที่มีลิขสิทธิ์ไปเผยแพร่ ขาย หรือแจกจ่ายต่อโดยไม่ได้รับอนุญาตจากเจ้าของลิขสิทธิ์
  • แอพไม่อ่านตอนที่ต้องซื้อหรือต้องล็อกอินจากเว็บต้นทาง และห้ามใช้แอพเพื่อหลีกเลี่ยงระบบชำระเงินหรือการป้องกันของเว็บไซต์ใด
  • ถ้าคุณเป็นเจ้าของลิขสิทธิ์และพบปัญหาเกี่ยวกับแอพ ติดต่อเราได้ตามข้อ 10

4. บริการภายนอกและค่าใช้จ่าย

  • การแปลใช้บริการของผู้ให้บริการ AI ผ่าน API Key ของคุณ คุณต้องปฏิบัติตามข้อกำหนดของผู้ให้บริการนั้น รวมถึงข้อกำหนดเรื่องเนื้อหา
  • ค่าใช้จ่ายทั้งหมดของ API Key เป็นของคุณ ตัวเลข token และค่าใช้จ่ายที่แอพแสดงเป็นค่าประมาณ ยอดจริงดูที่หน้าเว็บของผู้ให้บริการ แนะนำให้ตั้งวงเงินที่บัญชีผู้ให้บริการ
  • การดึงหน้าเว็บใช้ r.jina.ai หรือ proxy ที่คุณตั้งเอง บริการเหล่านี้อาจจำกัดการใช้งานหรือหยุดให้บริการได้

4.1 บริการแปลของ Dusktale (เข้าสู่ระบบ)

  • เมื่อเข้าสู่ระบบด้วยอีเมล คุณแปลผ่าน AI ที่เราจัดหาให้ได้ตามโควตา token ต่อเดือนของแพ็กเกจ โควตาเริ่มใหม่ทุกต้นเดือน (เวลา UTC) โควตาที่ไม่ได้ใช้ไม่สะสมไปเดือนถัดไป
  • จำนวนตอนที่แอพแสดงเป็นค่าประมาณ ตอนยาวหรือโหมดคุณภาพสูงใช้ token มากกว่า
  • เราเลือกและเปลี่ยนโมเดล AI ที่ใช้ได้ ปรับโควตาของแพ็กเกจฟรีได้ และอาจหยุดบริการชั่วคราวเพื่อดูแลระบบ แพ็กเกจฟรีไม่มีการรับประกันความพร้อมใช้งาน
  • บัญชีใช้ได้เฉพาะเจ้าของ ห้ามแชร์บัญชี ใช้สคริปต์เรียกบริการโดยไม่ผ่านแอพ หรือพยายามหลบเลี่ยงโควตา เราอาจระงับบัญชีที่ใช้งานผิดเงื่อนไขหรือผิดกฎหมาย
  • เนื้อหาที่ส่งไปแปลต้องเป็นไปตามข้อ 3 และข้อกำหนดด้านเนื้อหาของผู้ให้บริการ AI

5. ข้อห้าม

  • ใช้แอพทำสิ่งผิดกฎหมาย ละเมิดลิขสิทธิ์ หรือละเมิดสิทธิผู้อื่น
  • ใช้แอพดึงเว็บไซต์ถี่เกินควรจนรบกวนการทำงานของเว็บไซต์นั้น
  • ดัดแปลงแอพเพื่อเก็บหรือส่ง API Key หรือข้อมูลของผู้อื่น

6. คำแปลจาก AI

คำแปลสร้างโดยปัญญาประดิษฐ์ อาจไม่ถูกต้อง ไม่ครบ หรือใช้คำไม่เหมาะสม และไม่ใช่งานแปลอย่างเป็นทางการของเจ้าของลิขสิทธิ์

7. ข้อมูลและการสำรองข้อมูล

ข้อมูลของคุณอยู่ในเบราว์เซอร์บนเครื่องของคุณ อาจหายได้เมื่อล้างข้อมูลเว็บไซต์ เปลี่ยนเครื่อง หรือเบราว์เซอร์ลบข้อมูลเองเมื่อพื้นที่เต็ม คุณมีหน้าที่สำรองข้อมูลด้วยเมนูสำรองข้อมูลของแอพ

8. การรับประกันและความรับผิด

Dusktale ให้บริการ "ตามสภาพ" โดยไม่มีการรับประกันใดๆ เท่าที่กฎหมายอนุญาต เราไม่รับผิดต่อความเสียหายจากการใช้งาน ข้อมูลสูญหาย ค่าใช้จ่ายของ API Key ของคุณ คำแปลที่ผิดพลาด หรือการหยุดทำงานของบริการภายนอกหรือบริการแปลของ Dusktale

9. การเปลี่ยนแปลงบริการและข้อกำหนด

เราอาจเพิ่ม เปลี่ยน หรือหยุดฟีเจอร์ใดๆ และอาจปรับปรุงข้อกำหนดนี้ ฉบับล่าสุดจะอยู่ที่หน้านี้พร้อมวันที่ด้านบน หากในอนาคตมีบริการแบบชำระเงินหรือบัญชีผู้ใช้ จะมีข้อกำหนดเพิ่มเติมเรื่องราคา การชำระเงิน การยกเลิก และการคืนเงิน แจ้งก่อนเริ่มเรียกเก็บเงิน
