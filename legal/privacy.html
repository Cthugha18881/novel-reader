นโยบายความเป็นส่วนตัว

ฉบับวันที่ 8 ตุลาคม 2569 (2026) · ใช้กับ Dusktale ทั้งแบบใช้ API Key ของผู้ใช้เอง และบริการของ Dusktale ที่ต้องเข้าสู่ระบบ (อีเมลหรือบัญชี Google)

สรุปสั้นๆ
  • นิยาย ตอน คลังศัพท์ การตั้งค่า และ API Key อยู่ในเบราว์เซอร์บนเครื่องของคุณ เราไม่มีสำเนา ยกเว้นคุณเปิด "ซิงก์หลายเครื่อง" (ข้อ 4.1) ซึ่งไม่รวม API Key
  • ถ้าเข้าสู่ระบบ เราเก็บอีเมล จำนวน token ที่ใช้ และสถานะแพ็กเกจ (ไม่เก็บเนื้อหาที่แปล) ดูข้อ 4 และข้อ 8
  • ข้อความที่คุณส่งผ่านปุ่ม "ส่งความเห็น / แจ้งปัญหา" เก็บไว้เพื่อแก้ปัญหา ดูข้อ 4.2
  • เราไม่เก็บสถิติพฤติกรรมการใช้งาน ไม่มีโฆษณา และไม่ใช้คุกกี้ติดตามตัว (จำนวน token ของบริการแปลเก็บเพื่อคิดโควตาเท่านั้น)
  • เมื่อคุณใช้ฟีเจอร์แปลหรือดึงหน้าเว็บ ข้อมูลที่จำเป็นจะถูกส่งตรงจากเครื่องคุณไปยังบริการที่ระบุในข้อ 3 เท่านั้น

1. ผู้ให้บริการ

Dusktale (ชื่อเดิม NovelTranslate AI) เป็นเว็บแอพอ่านนิยายแปลด้วย AI พัฒนาและดูแลโดยผู้พัฒนา Dusktale ติดต่อเรื่องความเป็นส่วนตัวได้ที่ หน้า Issues ของโปรเจกต์บน GitHub

2. ข้อมูลที่อยู่ในเครื่องของคุณ

ข้อมูลต่อไปนี้เก็บใน IndexedDB และ localStorage ของเบราว์เซอร์ที่คุณใช้ และไม่ถูกส่งมาให้เรา

  • นิยายและตอนที่คุณเพิ่ม ทั้งต้นฉบับและคำแปล ภาพปกที่คุณใส่ บุ๊กมาร์กและโน้ต
  • คลังศัพท์ คู่มือเรื่อง บันทึกเหตุการณ์ ประวัติคำแปล และบทสนทนากับผู้ช่วย AI
  • การตั้งค่า สถิติการใช้ token ที่แอพนับเอง และบันทึกข้อผิดพลาด (ตัด API Key ออกแล้ว)
  • API Key ของผู้ให้บริการ AI และ Jina เก็บในเครื่องนี้ ถ้าเลือก "ไม่จำ API Key หลังปิดแท็บ" จะเก็บไว้เฉพาะระหว่างเปิดแท็บ

ไฟล์สำรองข้อมูลที่คุณดาวน์โหลดเป็นไฟล์ในเครื่องของคุณเอง และไม่มี API Key อยู่ในไฟล์

แยกตามบัญชี: เมื่อเข้าสู่ระบบ ข้อมูลข้างบนและ API Key จะเก็บแยกเป็นของบัญชีนั้น คนที่เข้าบัญชีอื่นหรือใช้แบบไม่เข้าสู่ระบบในเครื่องเดียวกันจะไม่เห็นในแอพ ข้อมูลที่ใช้ตอนไม่ได้เข้าสู่ระบบเป็นของโหมดไม่เข้าสู่ระบบ ซึ่งทุกคนที่ใช้เบราว์เซอร์นี้เห็นได้ ข้อมูลในเบราว์เซอร์ไม่ได้เข้ารหัส ผู้ที่เข้าถึงเครื่องและเครื่องมือของเบราว์เซอร์ได้อาจอ่านได้ เครื่องที่ใช้ร่วมกันควรเลือก "ออกจากระบบและลบข้อมูลของบัญชีนี้ในเครื่อง" เมื่อเลิกใช้

3. ข้อมูลที่ถูกส่งไปยังบริการภายนอก

แอพส่งข้อมูลจากเบราว์เซอร์ของคุณไปยังบริการเหล่านี้โดยตรง เฉพาะเมื่อคุณใช้ฟีเจอร์ที่ต้องใช้ บริการแต่ละรายมีนโยบายความเป็นส่วนตัวของตัวเอง

บริการข้อมูลที่ส่งเมื่อไร
ผู้ให้บริการ AI ที่คุณเลือก (Google Gemini, Anthropic Claude, OpenAI หรือผู้ให้บริการแบบ OpenAI-compatible เช่น OpenRouter)ต้นฉบับของตอน คำแปล คำศัพท์และข้อมูลตัวละครที่เกี่ยวข้อง คำถามที่ถามผู้ช่วย และ API Key ของคุณแปล สแกนคำศัพท์ ตรวจทาน ถามผู้ช่วย AI เทียบโมเดล
r.jina.ai (ตัวแปลงหน้าเว็บเป็นข้อความ)ลิงก์หน้าเว็บนิยายที่คุณวาง และ Jina API Key ถ้าใส่ไว้ดึงตอนจากลิงก์ เช็กตอนใหม่ ดึงสารบัญ
proxy สำรองที่คุณตั้งเอง (ถ้ามี)ลิงก์หน้าเว็บนิยายเมื่อ r.jina.ai ใช้ไม่ได้
Google Fontsที่อยู่ IP และข้อมูลเบราว์เซอร์ตามปกติของการโหลดฟอนต์ตอนเปิดแอพ
Dusktale (Vercel + Supabase) และ OpenRouterดูข้อ 4เฉพาะเมื่อเข้าสู่ระบบ และใช้บริการแปลของ Dusktale ซิงก์หลายเครื่อง หรือส่งความเห็น
Google (เข้าสู่ระบบด้วย Google)คำขอเข้าสู่ระบบ Google ส่งชื่อ อีเมล และรูปโปรไฟล์ของบัญชี Google ให้ Supabase เพื่อยืนยันตัวตนเมื่อกด "เข้าสู่ระบบด้วย Google"
Stripe (ระบบชำระเงิน)ดูข้อ 8เมื่อสมัครหรือจัดการแพ็กเกจ
GitHub Pages (ที่ฝากเว็บแอพ)ที่อยู่ IP และข้อมูลการเข้าเว็บตามปกติของเซิร์ฟเวอร์ตอนเปิดแอพ

แอพจำกัดปลายทางที่ส่งข้อมูลได้ด้วย Content-Security-Policy ให้มีเฉพาะบริการข้างบนและ Base URL ที่คุณตั้งเอง

4. เมื่อใช้บริการแปลของ Dusktale (เข้าสู่ระบบ)

ถ้าคุณเข้าสู่ระบบด้วยอีเมลหรือบัญชี Google

  • ข้อมูลบัญชี: อีเมล วันที่สมัครและเข้าสู่ระบบ และถ้าเข้าสู่ระบบด้วย Google จะมีชื่อและรูปโปรไฟล์จากบัญชี Google ด้วย เก็บที่ Supabase เพื่อยืนยันตัวตนและส่งอีเมลเข้าสู่ระบบ
  • ข้อมูลการใช้งาน: เวลา จำนวน token ขาเข้า/ขาออก ชื่อโมเดล และค่าใช้จ่ายของแต่ละคำขอ เพื่อคำนวณโควตาของแพ็กเกจ
  • เนื้อหาที่แปล: ต้นฉบับและข้อมูลประกอบการแปลถูกส่งผ่านเซิร์ฟเวอร์ของเรา (Vercel) ไปยัง OpenRouter และผู้ให้บริการโมเดล AI เพื่อสร้างคำแปล แล้วส่งคำแปลกลับมาที่เครื่องคุณ เซิร์ฟเวอร์ของเราไม่บันทึกเนื้อหา แต่ OpenRouter และผู้ให้บริการโมเดลอาจเก็บข้อมูลตามนโยบายของตน
  • การเข้าสู่ระบบในเครื่อง: token การเข้าสู่ระบบเก็บในเบราว์เซอร์เหมือน API Key ไม่อยู่ในไฟล์สำรอง ออกจากระบบหรือกด "ลบ API Key ทั้งหมด" เพื่อลบ
  • ระยะเวลาเก็บ: ข้อมูลการใช้งานเก็บไม่เกิน 24 เดือน บัญชีเก็บจนกว่าคุณจะขอลบ เมื่อลบบัญชี ข้อมูลการใช้งานของบัญชีนั้นจะถูกลบด้วย
  • ขอลบบัญชีหรือขอสำเนาข้อมูล: ติดต่อตามข้อ 1

4.1 ซิงก์หลายเครื่องและสำรองบนคลาวด์ (เมื่อเปิดใช้เอง)

  • ข้อมูลที่เก็บ: เมื่อคุณเปิด "ซิงก์อัตโนมัติ" ในหน้าตั้งค่า → ข้อมูล แอพจะบีบอัดแล้วเก็บสำเนาของชั้นหนังสือ (รวมตำแหน่งอ่าน) ตอนที่แปลทั้งต้นฉบับและคำแปล คลังศัพท์ คู่มือเรื่อง บันทึกเหตุการณ์ บุ๊กมาร์ก/โน้ต ภาพปก และบทสนทนากับผู้ช่วย AI ไว้ที่ Supabase ผูกกับบัญชีของคุณ
  • ไม่เก็บ: API Key, token การเข้าสู่ระบบ, ค่าตั้งของเครื่อง, ประวัติเวอร์ชันของตอน และสถิติการใช้งาน
  • ใครเข้าถึงได้: เฉพาะเครื่องที่เข้าสู่ระบบบัญชีของคุณ เราไม่นำเนื้อหาไปใช้หรือเผยแพร่ ผู้ดูแลระบบเข้าถึงฐานข้อมูลได้เพื่อดูแลระบบและแก้ปัญหาเท่านั้น
  • หยุดหรือลบ: ปิด "ซิงก์อัตโนมัติ" ได้ทุกเมื่อ (ข้อมูลในเครื่องยังอยู่) ขอลบข้อมูลบนคลาวด์ได้ตามข้อ 1 ถ้าแพ็กเกจหมดอายุ ข้อมูลยังอยู่และดาวน์โหลดคืนได้ ข้อมูลของบัญชีที่ไม่ได้ใช้งานและไม่มีแพ็กเกจเกิน 12 เดือนอาจถูกลบ โดยแจ้งทางอีเมลก่อน

4.2 ความเห็นและการแจ้งปัญหา

  • เมื่อเข้าสู่ระบบ: ข้อความที่คุณเขียน หมวดที่เลือก และอีเมลของบัญชี เก็บที่ Supabase เพื่อให้ผู้พัฒนาอ่านและตอบกลับ
  • ข้อมูลช่วยแก้ปัญหา (เลือกได้): ถ้าติ๊กแนบไว้ จะส่งรุ่นของแอพ ชนิดเบราว์เซอร์ ขนาดจอ แพ็กเกจ ผู้ให้บริการ AI ที่ตั้งไว้ จำนวนเรื่อง และข้อผิดพลาดล่าสุด ดูได้ก่อนส่ง ไม่รวม API Key, token การเข้าสู่ระบบ และเนื้อหานิยาย
  • เมื่อไม่ได้เข้าสู่ระบบ: แอพเปิดหน้า Issues ของ GitHub ที่กรอกข้อความไว้ให้ ข้อความนั้นเป็นสาธารณะเมื่อคุณกดส่งบน GitHub
  • ระยะเวลาเก็บ: ไม่เกิน 24 เดือน หรือจนกว่าคุณจะขอลบตามข้อ 1

5. ระยะเวลาเก็บและการลบข้อมูลในเครื่อง

ข้อมูลอยู่ในเครื่องจนกว่าคุณจะลบ ลบได้ในแอพ (ลบตอน ลบทั้งเรื่อง ลบ API Key ทั้งหมด) หรือล้างข้อมูลเว็บไซต์ของเบราว์เซอร์ ซึ่งลบทุกอย่างของแอพในเครื่องนั้น เราลบหรือกู้คืนข้อมูลแทนคุณไม่ได้ เพราะไม่มีสำเนาอยู่ที่เรา จึงควรสำรองข้อมูลเป็นระยะ

6. สิทธิของคุณตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล

คุณมีสิทธิขอเข้าถึง แก้ไข ลบ ขอสำเนา หรือคัดค้านการประมวลผลข้อมูลส่วนบุคคล ข้อมูลในเครื่องอยู่ในการควบคุมของคุณเอง ส่วนข้อมูลบัญชีและการใช้งานในข้อ 4 ขอได้ตามข้อ 1 สำหรับข้อมูลที่ส่งไปยังบริการภายนอกในข้อ 3 โปรดใช้ช่องทางของบริการนั้นโดยตรง หากมีคำถามติดต่อเราได้ตามข้อ 1

7. ผู้เยาว์

Dusktale ไม่ได้ออกแบบมาเพื่อเก็บข้อมูลของเด็ก ผู้ใช้อายุต่ำกว่า 20 ปีควรได้รับความยินยอมจากผู้ปกครองก่อนสมัครบัญชี สมัครแพ็กเกจแบบชำระเงิน หรือสมัครใช้บริการ AI ภายนอก

8. การชำระเงิน

การชำระเงินทำผ่าน Stripe ข้อมูลบัตรและบัญชีที่ใช้จ่ายกรอกที่หน้าของ Stripe โดยตรง เราไม่ได้รับหรือเก็บเลขบัตร เราเก็บเฉพาะรหัสลูกค้าของ Stripe สถานะการสมัคร แพ็กเกจ และวันหมดอายุ เพื่อเปิดสิทธิ์ตามแพ็กเกจ Stripe เก็บข้อมูลการชำระเงินตามนโยบายของ Stripe และกฎหมายที่เกี่ยวข้อง

9. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้ ฉบับล่าสุดจะอยู่ที่หน้านี้พร้อมวันที่ด้านบน การเปลี่ยนแปลงที่สำคัญจะแจ้งในแอพ
