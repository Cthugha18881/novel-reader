นโยบายความเป็นส่วนตัว

ฉบับวันที่ 7 ตุลาคม 2569 (2026) · ใช้กับ Dusktale ทั้งแบบใช้ API Key ของผู้ใช้เอง และบริการแปลของ Dusktale (เข้าสู่ระบบด้วยอีเมล)

สรุปสั้นๆ
  • นิยาย ตอน คลังศัพท์ การตั้งค่า และ API Key อยู่ในเบราว์เซอร์บนเครื่องของคุณเท่านั้น เราไม่มีสำเนา
  • ถ้าเข้าสู่ระบบเพื่อใช้บริการแปลของ Dusktale เราเก็บอีเมลและจำนวน token ที่ใช้ (ไม่เก็บเนื้อหาที่แปล) ดูข้อ 4
  • เราไม่เก็บสถิติการใช้งาน ไม่มีโฆษณา และไม่ใช้คุกกี้ติดตามตัว
  • เมื่อคุณใช้ฟีเจอร์แปลหรือดึงหน้าเว็บ ข้อมูลที่จำเป็นจะถูกส่งตรงจากเครื่องคุณไปยังบริการที่ระบุในข้อ 3 เท่านั้น

1. ผู้ให้บริการ

Dusktale (ชื่อเดิม NovelTranslate AI) เป็นเว็บแอพอ่านนิยายแปลด้วย AI พัฒนาและดูแลโดยผู้พัฒนา Dusktale ติดต่อเรื่องความเป็นส่วนตัวได้ที่ หน้า Issues ของโปรเจกต์บน GitHub

2. ข้อมูลที่อยู่ในเครื่องของคุณ

ข้อมูลต่อไปนี้เก็บใน IndexedDB และ localStorage ของเบราว์เซอร์ที่คุณใช้ และไม่ถูกส่งมาให้เรา

  • นิยายและตอนที่คุณเพิ่ม ทั้งต้นฉบับและคำแปล ภาพปกที่คุณใส่ บุ๊กมาร์กและโน้ต
  • คลังศัพท์ คู่มือเรื่อง บันทึกเหตุการณ์ ประวัติคำแปล และบทสนทนากับผู้ช่วย AI
  • การตั้งค่า สถิติการใช้ token ที่แอพนับเอง และบันทึกข้อผิดพลาด (ตัด API Key ออกแล้ว)
  • API Key ของผู้ให้บริการ AI และ Jina เก็บในเครื่องนี้ ถ้าเลือก "ไม่จำ API Key หลังปิดแท็บ" จะเก็บไว้เฉพาะระหว่างเปิดแท็บ

ไฟล์สำรองข้อมูลที่คุณดาวน์โหลดเป็นไฟล์ในเครื่องของคุณเอง และไม่มี API Key อยู่ในไฟล์

3. ข้อมูลที่ถูกส่งไปยังบริการภายนอก

แอพส่งข้อมูลจากเบราว์เซอร์ของคุณไปยังบริการเหล่านี้โดยตรง เฉพาะเมื่อคุณใช้ฟีเจอร์ที่ต้องใช้ บริการแต่ละรายมีนโยบายความเป็นส่วนตัวของตัวเอง

บริการข้อมูลที่ส่งเมื่อไร
ผู้ให้บริการ AI ที่คุณเลือก (Google Gemini, Anthropic Claude, OpenAI หรือผู้ให้บริการแบบ OpenAI-compatible เช่น OpenRouter)ต้นฉบับของตอน คำแปล คำศัพท์และข้อมูลตัวละครที่เกี่ยวข้อง คำถามที่ถามผู้ช่วย และ API Key ของคุณแปล สแกนคำศัพท์ ตรวจทาน ถามผู้ช่วย AI เทียบโมเดล
r.jina.ai (ตัวแปลงหน้าเว็บเป็นข้อความ)ลิงก์หน้าเว็บนิยายที่คุณวาง และ Jina API Key ถ้าใส่ไว้ดึงตอนจากลิงก์ เช็กตอนใหม่ ดึงสารบัญ
proxy สำรองที่คุณตั้งเอง (ถ้ามี)ลิงก์หน้าเว็บนิยายเมื่อ r.jina.ai ใช้ไม่ได้
Google Fontsที่อยู่ IP และข้อมูลเบราว์เซอร์ตามปกติของการโหลดฟอนต์ตอนเปิดแอพ
Dusktale (Vercel + Supabase) และ OpenRouterดูข้อ 4เฉพาะเมื่อเข้าสู่ระบบและใช้บริการแปลของ Dusktale
GitHub Pages (ที่ฝากเว็บแอพ)ที่อยู่ IP และข้อมูลการเข้าเว็บตามปกติของเซิร์ฟเวอร์ตอนเปิดแอพ

แอพจำกัดปลายทางที่ส่งข้อมูลได้ด้วย Content-Security-Policy ให้มีเฉพาะบริการข้างบนและ Base URL ที่คุณตั้งเอง

4. เมื่อใช้บริการแปลของ Dusktale (เข้าสู่ระบบ)

ถ้าคุณเลือก "Dusktale — ไม่ต้องใช้ API Key" และเข้าสู่ระบบด้วยอีเมล

  • ข้อมูลบัญชี: อีเมล วันที่สมัครและเข้าสู่ระบบ เก็บที่ Supabase (ศูนย์ข้อมูลสิงคโปร์) เพื่อยืนยันตัวตนและส่งอีเมลเข้าสู่ระบบ
  • ข้อมูลการใช้งาน: เวลา จำนวน token ขาเข้า/ขาออก ชื่อโมเดล และค่าใช้จ่ายของแต่ละคำขอ เพื่อคำนวณโควตาของแพ็กเกจ
  • เนื้อหาที่แปล: ต้นฉบับและข้อมูลประกอบการแปลถูกส่งผ่านเซิร์ฟเวอร์ของเรา (Vercel) ไปยัง OpenRouter และผู้ให้บริการโมเดล AI เพื่อสร้างคำแปล แล้วส่งคำแปลกลับมาที่เครื่องคุณ เซิร์ฟเวอร์ของเราไม่บันทึกเนื้อหา แต่ OpenRouter และผู้ให้บริการโมเดลอาจเก็บข้อมูลตามนโยบายของตน
  • การเข้าสู่ระบบในเครื่อง: token การเข้าสู่ระบบเก็บในเบราว์เซอร์เหมือน API Key ไม่อยู่ในไฟล์สำรอง ออกจากระบบหรือกด "ลบ API Key ทั้งหมด" เพื่อลบ
  • ระยะเวลาเก็บ: ข้อมูลการใช้งานเก็บไม่เกิน 24 เดือน บัญชีเก็บจนกว่าคุณจะขอลบ เมื่อลบบัญชี ข้อมูลการใช้งานของบัญชีนั้นจะถูกลบด้วย
  • ขอลบบัญชีหรือขอสำเนาข้อมูล: ติดต่อตามข้อ 1

5. ระยะเวลาเก็บและการลบข้อมูลในเครื่อง

ข้อมูลอยู่ในเครื่องจนกว่าคุณจะลบ ลบได้ในแอพ (ลบตอน ลบทั้งเรื่อง ลบ API Key ทั้งหมด) หรือล้างข้อมูลเว็บไซต์ของเบราว์เซอร์ ซึ่งลบทุกอย่างของแอพในเครื่องนั้น เราลบหรือกู้คืนข้อมูลแทนคุณไม่ได้ เพราะไม่มีสำเนาอยู่ที่เรา จึงควรสำรองข้อมูลเป็นระยะ

6. สิทธิของคุณตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล

คุณมีสิทธิขอเข้าถึง แก้ไข ลบ ขอสำเนา หรือคัดค้านการประมวลผลข้อมูลส่วนบุคคล ข้อมูลในเครื่องอยู่ในการควบคุมของคุณเอง ส่วนข้อมูลบัญชีและการใช้งานในข้อ 4 ขอได้ตามข้อ 1 สำหรับข้อมูลที่ส่งไปยังบริการภายนอกในข้อ 3 โปรดใช้ช่องทางของบริการนั้นโดยตรง หากมีคำถามติดต่อเราได้ตามข้อ 1

7. ผู้เยาว์

Dusktale ไม่ได้ออกแบบมาเพื่อเก็บข้อมูลของเด็ก และไม่มีการสมัครสมาชิก ผู้ใช้อายุต่ำกว่า 20 ปีควรได้รับความยินยอมจากผู้ปกครองก่อนสมัครใช้บริการ AI ภายนอก

8. เมื่อมีบริการแบบชำระเงิน

หากมีแพ็กเกจแบบชำระเงิน การซิงก์ หรือสำรองข้อมูลบนคลาวด์ เราจะปรับปรุงนโยบายนี้และแจ้งให้ทราบก่อนเริ่มเก็บข้อมูลใหม่ เช่น ข้อมูลการชำระเงิน (ผ่านผู้ให้บริการรับชำระเงิน ไม่ผ่านเรา) และข้อมูลที่ซิงก์

9. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้ ฉบับล่าสุดจะอยู่ที่หน้านี้พร้อมวันที่ด้านบน การเปลี่ยนแปลงที่สำคัญจะแจ้งในแอพ
